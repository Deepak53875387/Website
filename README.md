## 🚀 Live Site

Your portfolio is ready to go live! Follow these simple steps:

### Option 1: GitHub Pages (Recommended - Free & Easy)

1. **Go to your GitHub repository**: https://github.com/Deepak53875387/Website

2. **Enable GitHub Pages**:
   - Click on **Settings** (top navigation)
   - Scroll down to **Pages** (left sidebar)
   - Under **Source**, select:
     - Branch: `claude/create-portfolio-page-AmH40` (or `main` after merging)
     - Folder: `/ (root)`
   - Click **Save**

3. **Access your live site**:
   - Your portfolio will be live at: `https://deepak53875387.github.io/Website/`
   - It may take 1-2 minutes to build

### Option 2: Merge to Main Branch

If you want to merge this to the main branch first:

1. Go to: https://github.com/Deepak53875387/Website/pull/new/claude/create-portfolio-page-AmH40
2. Click **Create Pull Request**
3. Review and click **Merge Pull Request**
4. Then follow Option 1 above, but select `main` branch
